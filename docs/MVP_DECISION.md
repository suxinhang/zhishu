# 知枢网站 MVP 版本 - 产品决策文档

## 产品经理最终决策

### 首页设计
- Logo: 文字 "知枢" + 🧠 图标
- 导航: 首页、分类、关于
- 搜索: 首页中央大搜索框
- 卡片布局: PC 4列, 手机 2列
- 分类筛选: 单选切换

### 智能体卡片
- 图标: 64px 圆形
- 名称: 最多10字
- 简介: 最多30字
- 按钮: "立即体验"
- hover: 上浮 + 阴影效果

### 详情页
- 显示: 图标、名称、简介、分类
- 对话入口: 跳转独立页面

### 对话页
- 仅文字消息
- 模拟响应: 固定预设回复
- 不保存历史
- 多行输入 + 发送按钮

### 技术栈
- 前端: Vue3 + Vite + Tailwind CSS
- 后端: FastAPI + PostgreSQL
- 图标: Heroicons + Emoji
