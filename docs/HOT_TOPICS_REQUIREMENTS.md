## 三、数据库设计

### 3.1 平台表
```sql
CREATE TABLE platforms (
    id INTEGER PRIMARY KEY,
    name VARCHAR(50),      -- 微博、知乎、抖音等
    icon VARCHAR(20),      -- 平台图标/emoji
    url VARCHAR(200),      -- 平台热榜URL
    sort INTEGER           -- 排序
);
```

### 3.2 分类表
```sql
CREATE TABLE categories (
    id INTEGER PRIMARY KEY,
    name VARCHAR(50),      -- 科技、财经、娱乐等
    icon VARCHAR(20),
    sort INTEGER
);
```

### 3.3 热点表
```sql
CREATE TABLE hot_topics (
    id INTEGER PRIMARY KEY,
    title VARCHAR(200),       -- 热点标题
    platform_id INTEGER,      -- 来源平台
    category_id INTEGER,      -- 所属分类
    hot_value INTEGER,        -- 热度值
    rank INTEGER,             -- 平台内排名
    url VARCHAR(500),         -- 原链接
    summary TEXT,             -- AI摘要（可选）
    created_at DATETIME,
    updated_at DATETIME
);
```

## 四、API接口设计

### 4.1 平台列表
```
GET /api/platforms
Response: [{id, name, icon, url}]
```

### 4.2 分类列表
```
GET /api/categories
Response: [{id, name, icon}]
```

### 4.3 热点列表
```
GET /api/topics?platform=X&category=Y&sort=hot
Response: [{id, title, platform_name, hot_value, rank, url}]
```

### 4.4 热点详情
```
GET /api/topics/{id}
Response: {id, title, content, platform, hot_value, url, summary}
```

### 4.5 热门热点
```
GET /api/topics/hot
Response: TOP 10 热门热点
```

## 六、技术方案

### 6.1 数据来源
| 方案 | 说明 |
|------|------|
| 方案A：API抓取 | 定时爬取各平台热榜API |
| 方案B：人工录入 | 后台手动添加热点数据（MVP阶段） |
| 方案C：第三方数据源 | 使用热榜聚合API服务 |

**MVP建议：方案B（人工录入）+ 方案C（如有免费API）**

### 6.2 定时更新
```python
# 后端定时任务（可选）
from apscheduler.schedulers.background import BackgroundScheduler

scheduler = BackgroundScheduler()
scheduler.add_job(update_hot_topics, 'interval', minutes=30)
scheduler.start()
```
