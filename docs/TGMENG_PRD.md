# 糖果梦热榜 - 产品需求文档 (PRD)

## 一、产品定位

**产品名称：** 糖果梦热榜（复刻版）  
**产品类型：** 全网实时热榜聚合 + AI 分析  
**目标用户：** 
- 热点追踪者
- 互联网从业者
- 投资理财人群
- 泛娱乐用户

---

## 二、页面结构

### 2.1 首页 `/`
**功能：** 热榜聚合展示

| 区域 | 内容 |
|---|---|
| 顶部导航 | Logo + 分类导航 + 搜索框 |
| 模式切换 | AI模式 / 糖果模式 |
| 热榜卡片 | 按分类展示热点 |
| 排序切换 | 热门 / 最新 / 糖果指数 |

### 2.2 分类页面
- `/community` - 社区热榜
- `/finance` - 财经热榜
- `/tech` - 科技热榜
- `/entertainment` - 娱乐热榜
- `/game` - 游戏热榜

### 2.3 功能页面
- `/about` - 关于页面
- `/function` - 功能介绍

---

## 三、核心功能

### 3.1 热榜聚合
- 200+ 平台热点聚合
- 实时更新（每分钟）
- 分类展示

### 3.2 AI 分析
- 每5分钟自动总结
- 深度洞察
- 趋势预测

### 3.3 糖果指数
- AI 客观评分
- 热度计算
- 排名生成

### 3.4 搜索功能
- 关键词搜索
- 分类筛选
- 历史记录

### 3.5 个性化
- 自定义站点
- 收藏功能
- 评论功能

---

## 四、数据模型

### 热点表 (hot_topics)
```sql
id, title, source, category, score, 
view_count, comment_count, created_at
```

### 分类表 (categories)
```sql
id, name, icon, sort
```

### 数据源表 (sources)
```sql
id, name, url, category, enabled
```
