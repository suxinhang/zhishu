## 网站功能清单

### 核心功能
1. ✅ 全网实时热榜聚合
2. ✅ AI 总结分析（每5分钟）
3. ✅ 深度洞察与趋势预测
4. ✅ 糖果指数（AI评分）
5. ✅ 词云统计
6. ✅ 热点检索
7. ✅ 个性化自定义

### 页面结构
- 首页 `/` - 热榜聚合展示
- 社区 `/community` - V2EX、知乎、虎扑等讨论
- 财经 `/finance` - 财经资讯聚合
- 科技 `/tech` - 科技资讯
- 娱乐 `/entertainment` - 娱乐资讯
- 游戏 `/game` - 游戏资讯
- 关于 `/about` - 平台介绍
- 功能 `/function` - 功能说明
