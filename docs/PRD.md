# 知枢网站 - 产品需求文档 (PRD)

## 一、产品定位
**知枢 - 智能体开发平台**：一个智能体聚合/展示平台，用户可以浏览、搜索、对话各类 AI 智能体。

## 二、目标用户
- AI 智能体开发者（发布智能体）
- 智能体使用者（查找、对话智能体）
- 企业用户（定制智能体服务）

## 三、核心功能模块

### 1. 首页
- Logo + 品牌展示
- 搜索框（搜索智能体）
- 智能体分类展示
- 热门智能体推荐

### 2. 智能体列表/展示区
- 智能体卡片展示：
  - 图标/头像
  - 名称
  - 简介/描述
  - "对话"按钮
- 分类标签（陪伴、写作、翻译、绘画、编程、产品等）
- 瀑布流/网格布局

### 3. 搜索功能
- 关键词搜索
- 分类筛选
- 搜索结果展示

### 4. 智能体详情页
- 智能体完整介绍
- 功能说明
- 对话入口
- 评价/评分

### 5. 对话功能
- 与智能体实时对话
- 对话历史记录
- 多轮对话支持

### 6. 用户系统（可选二期）
- 用户注册/登录
- 个人中心
- 收藏智能体
- 对话历史管理

## 四、技术架构

### 前端 (Vue.js)
- Vue 3 + Vite
- Vue Router（路由）
- Pinia（状态管理）
- Tailwind CSS / SCSS（样式）
- 组件化设计

### 后端 (Python)
- FastAPI / Flask
- SQLAlchemy ORM
- PostgreSQL / MySQL
- Redis（缓存）
- RESTful API

### 数据库设计
- 智能体表（id, name, description, icon, category, creator_id）
- 用户表（id, name, email, password）
- 对话记录表（id, user_id, agent_id, content, timestamp）
- 分类表（id, name, icon）

## 五、页面列表
| 页面 | 路径 | 功能 |
|---|---|---|
| 首页 | / | 搜索、智能体展示 |
| 搜索结果 | /search?q=xxx | 搜索结果列表 |
| 智能体详情 | /agent/:id | 详情、对话入口 |
| 对话页 | /chat/:id | 与智能体对话 |
| 用户中心 | /user | 个人信息（二期） |

## 六、开发里程碑

### Phase 1: MVP（核心功能）
- 首页布局 + 智能体展示
- 搜索功能
- 智能体详情页
- 基础 API

### Phase 2: 对话功能
- 实时对话界面
- 对话历史存储
- 多轮对话逻辑

### Phase 3: 用户系统
- 注册/登录
- 个人中心
- 收藏、历史管理
