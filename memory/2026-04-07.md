# 2026-04-07 工作记录

## 🎨 知枢设计系统重构

### 任务背景
用户要求基于竞品分析进行实际产品设计，而非单纯调研。要有知枢自己的设计风格。

### 设计理念：**"知识神经网络"**
智能体就像神经网络中的节点，相互连接、协作。视觉上体现这种"连接感"。

### 实现内容

#### 1. Tailwind 配色系统
- 主色：深蓝渐变 `#0F172A → #1E3A8A`（科技感）
- 强调色：琥珀金 `#F59E0B`（突出热度）
- 中性色：Slate 系灰色
- 自定义阴影：card、card-hover、glow、glow-amber

#### 2. 全局样式 (main.css)
- 网络背景图案（网格连线）
- 卡片发光边框效果
- 节点装饰元素
- 连线动画
- 渐变文字
- 热度指示器样式
- 搜索框/分类标签/按钮样式
- 消息气泡样式
- 滚动条美化

#### 3. 页面重设计

| 页面 | 更新内容 |
|------|----------|
| App.vue | 毛玻璃导航栏、渐变Logo、页脚 |
| Home.vue | Hero区、热门横向滚动、筛选排序区、卡片网格 |
| AgentCard.vue | 顶部装饰线、评分星星动画、热度badge、双按钮 |
| AgentDetail.vue | 返回链接、智能体卡片、评分区域、功能特点 |
| Chat.vue | 在线状态、消息气泡、加载动画、快捷提示词 |
| Category.vue | 分类网格、统计信息、底部装饰 |
| About.vue | Hero、特点展示、技术栈 |

#### 4. 视觉差异点（vs 糖果梦热榜）
| 糖果梦 | 知枢 |
|--------|------|
| 扁平卡片 | 浮动节点卡片（发光边框） |
| 简单背景 | 网络连线图案 |
| 普通热度标签 | 动态热度badge（脉冲动画） |
| 基础评分 | 星星动画 + 人数显示 |
